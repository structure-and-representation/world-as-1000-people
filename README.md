# 世界がもしボールプールだったら

人口をボールに置き換え、いくつかの切り口で分けて見る立体グラフです。
分け方を切り替えると、仕切りが消えてボールが崩れ、新しい筒に積み直されます。

| ページ | URL | ボール1個 | 分け方 | 年 |
|---|---|---|---|---|
| 世界がもしボールプールだったら | https://world-as-a-ball-pool.structure-and-representation.com/ | 1000万人 | 地域・年齢・所得 | 1950〜2100年（25年刻み） |
| 日本がもしボールプールだったら | https://world-as-a-ball-pool.structure-and-representation.com/japan/ | 10万人 | 地域・年齢・男女 | 1925〜2050年（25年刻み） |

- ボール1個の人数はどの年でも同じです。年によってボールの数が変わります
- 年：レールの上のつまみを動かすか、年をタップして選びます
- 分ける：3つの切り口から2つまで。1つめは横に、2つめは奥に分かれます。もう一度押すと外れます
- 色：分け方とは別の切り口を選べます
- 筒をタップすると、ボールが跳ねて、その筒の内訳が出ます
- 日本版では、地域の筒をタップして「中を見る」を押すと、その地域のボールが都道府県ごとに並び直します。「全国に戻る」で元に戻ります
- 筒の底面積はすべて同じで、年を変えても変わりません。高さがそのまま人数を表し、年どうしでも比べられます

## 構成

| パス | 内容 |
|---|---|
| `index.html`, `japan/index.html` | 公開するページ（データとスクリプトを埋め込み済み。それぞれ1枚で動きます） |
| `ogp.png`, `japan/ogp.png` | 共有用の画像（1200×630） |
| `src/head.html`, `src/app.js` | 2ページ共通のひな形とスクリプト |
| `src/pages/*.json` | ページごとの設定（タイトル、説明文、切り口の名前と色） |
| `data/world.json`, `data/japan.json` | 各年のボールの割り当て |
| `scripts/prep_world.py`, `scripts/prep_japan.py` | 元データからボールの割り当てを作る |
| `scripts/balls.py` | 人口をボールに割り当てる共通の処理 |
| `scripts/build.py` | `src/` と `data/` から各ページを組み立てる |

描画には three.js r128 を cdnjs から読み込んでいます。

## データの作り直し

```sh
pip install rdata pandas openpyxl

# 世界
git clone --depth 1 https://github.com/PPgp/wpp2024.git
python3 scripts/prep_world.py wpp2024/data data/world.json

# 日本（census.csv と ipss/01.xlsx〜47.xlsx は下記の出典から取得）
python3 scripts/prep_japan.py census.csv ipss data/japan.json

python3 scripts/build.py .
```

## ボールの割り当て（共通）

- 各年のボール数は、その年の人口をボール1個の人数で割って丸めた値です。
- 各年のボールは、3つの切り口を掛け合わせた区分に、最大剰余法で割り当てています（日本版は下記のとおり2段階）。各グループの個数には1個程度のずれが出ます。
- 年を変えたとき、同じ区分に残れるボールは残し、足りない区分には他の区分から移すか、新しいボールを足しています。個々のボールが特定の人や国を表すわけではありません。

## 世界のデータ

- 出典：United Nations, DESA, Population Division. World Population Prospects 2024（CC BY 3.0 IGO）
  https://population.un.org/wpp/
- 取得元：Rパッケージ wpp2024（https://github.com/PPgp/wpp2024）の1歳刻み・各年のデータ
- 時点：各年7月1日。パッケージの値は各年12月31日時点なので、前年末と当年末の平均で年央の値にしています。
  2025年の世界人口は8,231,613千人で、国連の公表値と一致します。
- 2025年以降は中位推計です。
- ボール数：1950年249、1975年407、2000年617、2025年823、2050年966、2075年1025、2100年1018
- 年齢は 0〜14歳、15〜64歳、65歳以上の3区分に集計しています。
- 所得グループは、同データが採用する世界銀行の分類を、すべての年に当てはめています。過去や将来の所得水準を表すものではありません。
  分類のない国・地域（ベネズエラなど）は「分類なし」としています。

## 日本のデータ

- 1925・1950・1975・2000年：総務省統計局「国勢調査」時系列データ 表3「年齢（5歳階級），男女別人口－都道府県（大正9年～平成27年）」
  https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&toukei=00200521&tstat=000001011777&cycle=0&tclass1=000001094741&tclass2val=0
- 2025・2050年：国立社会保障・人口問題研究所「日本の地域別将来推計人口（令和5（2023）年推計）」3. 都道府県・市区町村別の男女・年齢（5歳）階級別将来推計人口（都道府県ごとのExcelの先頭シート）
  https://www.ipss.go.jp/pp-shicyoson/j/shicyoson23/t-page.asp
- 時点：各年10月1日。
- ボール数：1925年597、1950年841、1975年1119、2000年1269、2025年1233、2050年1047
- 地域は47都道府県を6つにまとめています：北海道・東北（北海道〜福島）、関東（茨城〜神奈川）、中部（新潟〜愛知）、近畿（三重〜和歌山）、中国・四国（鳥取〜高知）、九州・沖縄（福岡〜沖縄）。
- 年齢は 0〜14歳、15〜64歳、65歳以上の3区分に集計しています。
- 国勢調査の総数には年齢不詳が含まれます。不詳の分は、都道府県・男女ごとの年齢構成に比例して配分しています。
- 1950年は、時系列データに収録されている沖縄県の値を含みます。
- ボールはまず地域×年齢×男女の36区分に割り当て、そのあと各区分のボールを地域内の都道府県に割り振っています。地域の個数は都道府県まで細かくしても変わりません。都道府県の個数は、県の人口を10万人で割った値から最大で1.4個ほどずれます。そのため、県の筒をタップしたときは実際の人口も表示します。
